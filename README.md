# Sistema de Gestao Clinica

Repositorio academico para desenvolvimento de uma API de gestao clinica com foco em usuarios, pacientes, consultas e prontuarios.

## Stack

- TypeScript
- Node.js
- Express.js
- MySQL
- Drizzle ORM
- Zod

## Fluxo de Trabalho

O fluxo oficial do projeto e:

1. `develop`
2. `feature/*`
3. Pull Request
4. Revisao
5. Merge em `develop`
